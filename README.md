# rrlogind
Historical archive of the rrlogind Road Runner login daemon

This utility was written in the late 1990's as an authentication
client for the Time Warner Cable Road Runner cable modem network.

At the time it was written, Road Runner was one of the only broadband
Internet services widely available to the public. Home "routers" where
not yet available. This daemon allowed the use of a small Linux system
to provide NAT features to a home network. This eventually evolved into 
the Coyote Linux project.
